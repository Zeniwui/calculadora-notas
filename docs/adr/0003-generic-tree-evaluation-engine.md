# 0003. Motor de evaluación genérico basado en árbol declarativo

Para procesar cualquier guía docente universitaria sin acoplar lógica imperativa al código de la interfaz de usuario, se decide representar las asignaturas como árboles declarativos de bloques y elementos evaluables con pesos, notas mínimas y reglas de agregación.

Un único motor matemático universal ejecuta tanto la simulación directa (cálculo ponderado hacia adelante y verificación de topes reglamentarios) como la simulación inversa (despeje de notas necesarias sobre elementos pendientes con distribución balanceada y fijación de valores), generando además el desglose paso a paso de fórmulas y condiciones.
